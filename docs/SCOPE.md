# Scope freeze — 4-hour MVP

## In scope
- Streamlit demonstration UI.
- Synthetic farmer cohort (50 rows).
- Manual farm context and stage selector.
- Demonstration risk flags for maize water-stress concern near flowering, tomato wet-weather monitoring, and onion wet-weather monitoring.
- Optional Groq LLM call with deterministic fallback.
- Basic SMS GSM-7/160-character validator.
- Simulated USSD menu.
- SQLite advisory log and pytest checks.

## Out of scope
- Real telecom delivery, registration/consent workflow, forecast ingestion, sourced GDD, agronomically validated risk thresholds, RAG corpus, production DB security, real-user study, irrigation model, voice, image diagnosis and live deployment.
