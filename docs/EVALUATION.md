# Evaluation — MVP

## Status
Evaluation harness is a minimal software test suite. It does not represent a farmer study or agronomic validation.

## Tests
- GSM-7-safe text check
- SMS length check
- Demo maize risk flag
- No-flag fallback

## Next evaluation design
Compare raw weather messaging, deterministic template, ungrounded LLM, and retrieval-grounded/validated LLM on a preregistered case set. For the MVP, weather, retrieval and expert data are absent, so these comparisons are future work.

Report actual runs only. Do not claim performance from synthetic examples.
