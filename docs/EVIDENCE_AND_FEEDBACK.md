# Evidence and feedback

The evidence registry is a placeholder catalog. Entries are not verified citations. A deployment requires curated authoritative sources, date/version tracking, review by qualified agricultural extension specialists, and a process for retiring outdated guidance.

The feedback table stores simulated advisory feedback in a local database. It is not a farmer study. Any future real-world collection requires consent, data minimization, review of applicable ethics and privacy requirements, and a clear retention/deletion policy.
